Built for 2026, not a tutorial from 2014.

Keyword chatbots dump “I don’t understand” on every real question. Lumen is a small product: reliable tools, honest limits, a shippable website, and a path to LLMs that doesn’t brick the demo.

01 · Product

A site interviewers can click

GitHub Pages hosts the full experience. The JavaScript engine is a sibling of the Python engine, so the demo never depends on a sleeping free-tier server.

02 · Engine

Intents you can unit test

Scored pattern matching plus safe math, unit conversion, session notes, interview coaching, and crisis-safe wellbeing copy. No `eval()` of user code.

03 · API

FastAPI when you need it

Health, capabilities, CORS, Pydantic validation, optional LLM adapter.

04 · Trust

Privacy by default

On-device first. Memory is per-session. LLM calls only if you set a key.

05 · Craft

UI that feels finished

Typography, motion, chips, export, keyboard submit, reduced-motion support.

Architecture you can defend in a loop.

Client engine for the website. Server engine for production. Same behaviors, two runtimes.

browser  ──►  assets/engine.js   (GitHub Pages, zero ops)
   │
   └──►  POST /api/chat  ──►  app/engine.py  ──►  tools (math, units, time)
                                   │
                                   └── unknown + LLM_API_KEY ──► OpenAI-compatible API

Create the website in three moves.

01

GitHub Pages

Settings → Pages → Deploy from branch main → folder /. Your site is live at https://<user>.github.io/basic-chatbot/.

02

Optional API

docker compose up --build or uvicorn app.main:app --reload. Set LLM_API_KEY only if you want open-ended replies.

03

Custom domain

Add an A/CNAME in Pages. Keep the static demo even if the API is down — that’s the professional move.
